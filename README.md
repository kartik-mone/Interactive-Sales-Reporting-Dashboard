
# Interactive Sales Reporting Dashboard (Excel)

## Project Overview

This project demonstrates the creation of an **interactive sales reporting dashboard using Microsoft Excel**, designed to support accurate reporting, structured data analysis, and efficient administrative decision-making. The dashboard is built using Pivot Tables, Pivot Charts, slicers, and timelines to enable dynamic exploration of sales data.

The focus of this project is **data accuracy, reporting efficiency, and usability**, aligning with back-office, learning administration, and reporting support roles.

---

## Objectives

* Organize raw sales data into a **structured and analysis-ready format**
* Enable **quick filtering and drill-down** across time, region, and product
* Reduce manual reporting effort through **automated summaries and visuals**

---

## Tools & Techniques Used

* Microsoft Excel
* Pivot Tables & Pivot Charts
* Slicers and Timelines
* Data Cleaning & Formatting
* KPI Calculation (Total Sales, Revenue, Trends)

---

## Key Features

* Interactive dashboard with **real-time filtering**
* Monthly sales trend analysis
* Product and region-wise performance breakdown
* KPI overview for quick decision support

---

## Project Structure

*  **Sheet :** Raw and cleaned dataset – `Data`
* **Sheet :** Interactive dashboard with pivots, charts, and slicers – `Dashboard`

---

## Use Case

This dashboard can be used for:

* Operational and administrative reporting
* Management review and summary reporting
* Learning and training data analysis scenarios
* SLA-driven environments requiring **accuracy and consistency**

---

## Key Learnings

* Built structured reports using Excel Pivot Tables
* Improved attention to **data accuracy and consistency**
* Designed user-friendly dashboards for non-technical stakeholders

---

## Note

This project is created for **learning, reporting, and portfolio demonstration purposes** and does not contain real or sensitive business data.
